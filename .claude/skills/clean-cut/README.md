# Clean Cut (free)

A free Claude Code skill: drop in a raw talking-head clip and get back a clean vertical video.

- **Tight cut**: silences, breaths, repeated words and failed takes removed, with no clipped words.
- **Plain captions**: 2-4 words at a time, white, in your font, under your chin.
- **9:16, ready to post**, plus a smaller copy for your phone.

No hooks, graphics, B-roll or music: those are in the full Creator Skill Pack (20 editing templates).

## Install (2 minutes)

1. You need a Mac and Claude Code.
2. Drag this zip into Claude Code and say **"install this skill"**. Claude unzips it into `~/.claude/skills/clean-cut/`.
   (Or do it by hand: unzip it into `~/.claude/skills/`. In Finder: Cmd+Shift+G, type `~/.claude/skills`, drag the folder in.)
3. Start a new Claude Code session so it picks the skill up, then drop in a raw clip and say: **"clean cut this"**.

The first time, Claude asks a few quick questions (your name, your font, how you want transcription done) and checks
your computer for the tools it needs (Node, ffmpeg, HyperFrames). It tells you before it installs anything.

**Transcription:** ElevenLabs gives the best cuts (about $0.22 per hour of audio, needs an account and a key), or it
can run free on your own computer. Never paste the key into the chat: setup shows you how to add it yourself.

Your answers are saved once. If you get the full pack later, it starts from the same answers.
