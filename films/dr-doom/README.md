# DR. DOOM — THE MAKING OF A MONSTER

A 60-second, 16:9 kinetic-typography film retelling Victor von Doom's comic-book origin, drawn entirely in code in a locked three-colour palette (#FEC700 · #02462E · #000000).

- `dr-doom.mp4`: the film (1080p, 24 fps, −14 LUFS)
- `dr-doom.srt`: narration subtitles (not burned in; the film's own typography carries the on-screen text)
- `TREATMENT.md`: structure, movement identity of every word, beat sheet and sound design
- `CREDITS`: fonts, voice and tool licences

Unofficial fan piece: Doctor Doom is a Marvel character. No Marvel artwork or logos are used.

Built with the [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) tools (MIT). To rebuild, copy this folder to `films/dr-doom/` inside a Lemo-Opuscar clone, run `sh plugin/skills/lemo-opuscar/scripts/setup.sh deps voice` there, then `sh films/dr-doom/build.sh`.
