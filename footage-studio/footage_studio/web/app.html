Footage Studio

Point it at one project folder (a wedding, a shoot) and it builds a searchable clip library. Your original files are never moved or changed unless you ask.

ffmpeg is needed

Footage Studio reads clips with a free tool called ffmpeg, and it isn't installed on this computer yet. Install Homebrew from brew.sh, run brew install ffmpeg, then open Footage Studio again.
